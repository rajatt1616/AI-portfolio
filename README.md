# 🤖 AI Personal Portfolio Assistant

An interactive, responsive AI portfolio assistant powered by **Streamlit**, **Groq API**, and **Llama 3.3**.

🚀 [Try the Live App Here](https://rajat-portfolio.streamlit.app/)

---

## ⚡ Features
* 🚀 **Fast LLM Streaming:** Ultra-low latency chat powered by `llama-3.3-70b-versatile` via Groq.
* 🎨 **Glassmorphism UI:** Custom frosted glass theme with dark translucent styling.
* 📱 **Dual Responsive Layout:** Clean static wallpaper on PC and live animated video background on mobile.
* 💼 **Interactive Sidebar:** Quick access to downloadable resume, project links, and developer profiles.

---

## 🛠️ Tech Stack
**Python** | **Streamlit** | **Groq API** | **CSS3**

## 💻 Run Locally

To run this project on your machine:

1. **Clone & Install:**
   ```bash
   git clone https://github.com/rajatt1616/AI-Portfolio.git
   cd AI-Portfolio
   pip install -r requirements.txt


2. Add API Key: Create a .env file in the root directory:

   ```bash
   GROQ_API_KEY="your_groq_api_key"

3. Launch App:

```bash
   streamlit run app.py
