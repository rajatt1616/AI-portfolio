## Better UNO

Type:
Desktop Game Application

Description:

Better UNO is a Python-based implementation of the classic UNO card game built using the Pygame framework. The project recreates the core UNO gameplay experience by implementing card mechanics, turn-based gameplay, player interactions, and visual rendering through a custom graphical interface.

The game includes a complete UNO deck generation system, card distribution, playable card validation, special card effects, wild card color selection, player turn management, and win detection. The project focuses on translating real-world game rules into programming logic while managing complex game states and user interactions.


Repository:
https://github.com/rajatt1616/better-uno/blob/main/uno_final.py
